# Project Exodus Alpha v0.01 — START HERE

This is a consolidated **source audit** package, not a fully implemented or runtime-tested gameplay overhaul.

## Setup
1. Extract this ZIP into a normal folder (do not run the game inside the ZIP).
2. Open the extracted `Project_Exodus_Alpha_v0.01` folder in VS Code or Decentraland Creator Hub. It contains `scene.json`, `package.json`, `src/`, `assets/`, and `Images/`.
3. The GDD is already in `design/gdd.md`. Do **not** move it.
4. The cleanup report is in `design/cleanup-report.json` and the build status is in `design/BUILD_STATUS.md`.
5. Files set aside during cleanup are in `recovery/Project_Exodus_Recovery_Archive.zip`. Keep that archive for rollback; do not extract it into the active project unless restoring a specific file.
6. Install project dependencies following `package.json` and project README before running Creator Hub / build checks.

## Status
Initial audit and source consolidation only. FFP/TTP, AI, combat, HUD and other gameplay fixes are NOT confirmed implemented or tested. Runtime testing must be performed separately.
